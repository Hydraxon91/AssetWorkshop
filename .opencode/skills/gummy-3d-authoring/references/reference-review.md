# Reference interpretation and comparison

Use for supplied images and likeness claims. Technical calibration instructions
are in the handbook; stage evidence requirements belong to `stage-review.md`.

## Establish what is known

Keep four distinct categories in the current agreement:

1. **User decisions:** actual approved dimensions, scope, fidelity and authority.
2. **Observed evidence:** visible landmarks/contours with the source view identified.
3. **Working assumptions:** plausible interpretations not established by the image.
4. **Unresolved discrepancies:** competing views or observations affecting construction.

Identify which supplied view governs each consequential contour. Do not dismiss
a view based on an unsupported description. Show the relevant visible evidence;
if contradictory views would change the result, present the actual conflict and
options for decision. Do not turn an agent's assumption into an approved constraint.
Ask only about consequential ambiguity; perform ordinary visual interpretation
and disclose its uncertainty rather than asking the user to do all analysis.

## Dimensional authority

Classify dimensions in the existing asset work record before shaping:
- **Hard constraints:** required fit, interfaces or explicit user limits; changes
  require user approval even when they conflict with the drawing.
- **Scale anchors:** dimensions used to set overall scale; hold them unless the
  user approves changing the scale authority. Specify the measured feature and
  convention (for example overall height versus rim centre height).
- **Provisional dimensions:** estimates and adjustable proportions. In approved
  reference-led work, the modeller may revise these without another approval
  stop when inspected comparisons justify the change. Record original/revised
  values, reason, reference/view, uncertainty and before/after evidence; the
  parent independently reviews both shape and protected constraints.

Never silently demote an existing hard constraint or user commitment. If the
classification was not agreed and a consequential conflict arises, return it
for decision. Once agreed, ordinary provisional corrections within scope do not
need repeated permission. Shape priority does not authorize new parts, stages,
budgets, topology defects or changes to protected surfaces.
Prior local acceptance does not freeze a wrong whole-model shape. Parent may reopen
scoped provisional geometry within user authorization; workers cannot release
protection themselves. User requirements and scale anchors retain their authority.

Perspective, occlusion and stylized drawings limit measurement authority. A
single view does not establish hidden depth, circularity or an exact bore. Never
stretch the reference or report inferred dimensions as measured facts. If a
provisional change affects a protected interface or hard constraint, stop for
approval instead. Update dependent measurements/captures after approved changes.

## Show the comparison before a consequential edit

### Orientation is a separate check from registration

Record the model's up axis, meaningful part directions (for example spout/handle),
reference image-left/right and camera view/right/up axes in the same reference
record. A new symmetric body may not yet have an intrinsic front or back: state
the chosen design datum, not a claimed recovered fact. Judge asymmetric openings,
cuts and features in that frame. When orientation is ambiguous, show labelled
opposed views of the same candidate once; do not flip/stretch the image or rename
a camera to conceal a mismatch. Project key landmarks and high/low/facing features.

Plane placement, camera and overlay must derive from one recorded crop, origin,
uniform scale and axis mapping. Accurate pixel projection alone does not certify
the correct side or perspective. Preserve but invalidate old rankings after a
trace, camera or datum correction; regenerate affected evidence. A good body
contour score cannot excuse an opening facing the wrong direction. Record excluded
occluded intervals and rank orientation-valid candidates separately from controls.

Build the in-scene reference plane first. Even a single side view gets a locked,
uniformly scaled plane at recorded model-units/px (physical units only if established).
Do not judge proportions from a detached image viewer. Establish scale from a
declared dimension or explicit user decision, disclose projection uncertainty,
and never non-uniformly stretch the reference. A plane alone is not calibration.
Identify the intended contour and the comparison that will judge it. Confirm the
actual image/view, object, orientation, framing and visibility before changing shape.
Inspect both upper and lower outlines, openings and relevant structural landmarks;
an occluded base cannot certify the whole profile. Physical edges differ from paint,
shadows and overlapping components. Hidden geometry remains an assumption.

Separate visual resemblance from measurement. Stylized/gameplay-read work uses
declared dimensions and neutral visual-guide comparisons unless measured matching
was requested. Reference-faithful/reconstruction and requested dimensional matching
require locked comparison planes and aligned overlays at shape acceptance. Claim
measured matching only with supported calibration/projection; otherwise agree a
visual-guide substitute authority. Use the handbook's calibration procedure when
measured matching applies; never stretch to force agreement. Consequential conflicts
in scale/projection authority need a user decision.

Disclose every crop, registration, rotation, uniform scale and approximation used
in a comparison. Independent width/height normalization is not calibrated matching.
Preserving aspect ratio alone proves neither source accuracy nor correct calibration.
An approximate perspective comparison can inform resemblance but not establish
dimensions. State measurement uncertainty; do not tune below it.

## Decide from inspected evidence

Use identical framing for reference-only, readable model-edges-over-reference and
solid-model views in calibrated acceptance. Verify both reference and model edges
are actually visible. Hide unrelated planes and restore temporary settings.

Describe the changed contour, remaining mismatch and coverage: for example,
“the shoulder is closer in side overlay; the lower belly is still too narrow;
front width is unverified.” This is a scoped observation, not user approval.
Counts, dimensions and topology cannot certify correspondence. If the comparison
is unreliable, repair the comparison before using it to justify geometry changes.
Use stage-review's agreed primary-form or local-refinement threshold. Suggested
causes and unmeasured replacement dimensions are hypotheses, not newly established
constraints; a separate reviewer role or agent agreement does not validate them.
